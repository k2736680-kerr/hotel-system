# 酒店管家操作与交付指南

## 1. 第一次使用

1. 首次启动先创建管理员账号。账号使用字母、数字或下划线，密码至少8位并同时包含字母和数字。
2. 管理员首次登录后，系统会保留登录状态；下次打开程序会自动进入系统，除非主动退出登录。
3. 打开“系统与备份”，填写酒店名称、电话、地址、默认押金和默认入住/退房时间。
4. 打开“房间与房型”，先维护房型，再新增实际房间。
5. 打开“客户档案”，登记客户；居民身份证必须通过校验位检查。
6. 在正式录入前创建一次手动备份。

## 2. 日常前台流程

### 预订

打开“预订与入住”并选择“新建预订”，填写房间、客户、日期、成交价和定金。系统会拒绝同一房间的重叠预订。

预订到店时选择“办理入住”。取消预订时必须填写原因，已收定金会登记对应退款。

### 直接入住

在房态总览的空闲房间选择“办理入住”，确认客户、离店时间、成交价和押金。待清洁、维修、停用或时间冲突的房间不能入住。

### 在住操作

在“预订与入住”打开订单详情，可执行：

- 添加费用、优惠和收款。
- 作废错误手工费用。
- 对原收款办理不超过可退余额的退款。
- 添加或移除同住人；主住人不能移除。
- 续住；与后续预订冲突时系统会阻止。
- 换房；原房自动待清洁，新房转入住中。

### 退房

选择“办理退房”，核对费用、已收金额和应补/应退金额。退房成功后房间进入待清洁，保洁确认后在房态或房间管理中选择“确认已清洁”。

## 3. 报表和备份

- 顶栏右侧点击当前账号，可修改显示名称、修改密码或退出登录。
- “经营报表”按日期查看收入趋势、净收款趋势和入住率图表，也可导出 CSV。
- “操作日志”按日期、动作、关键字筛选并分页，日志持续保存在数据库中。
- “系统与备份”可创建或恢复 SQLite 备份。
- 恢复前系统会先自动备份当前数据库。
- 系统每天自动检查，并在正常退出时更新同一份 `auto-latest.sqlite` 滚动备份，只保留一份。
- “客户档案”支持独立导入和导出 CSV，这部分与完整数据库备份分开管理。
- 仍建议定期把手动备份复制到 U 盘、移动硬盘或其他受控磁盘。

## 4. 数据和使用边界

- 该版本只允许在一台电脑上使用，不要通过共享文件夹让多台电脑同时打开数据库。
- 卸载默认保留用户数据，但重装和升级前仍应手动备份。
- 覆盖安装或安装新版不会删除用户数据；数据库位于用户数据目录而不是安装目录，并会自动执行结构迁移。
- 身份证等数据保存在本机，请控制 Windows 账号和电脑访问权限。

## 5. 开发环境打包

在项目目录安装依赖并运行测试：

```powershell
npm install
npm test
```

生成安装包：

```powershell
npm run dist
```

安装包输出位置：

```text
release\HotelButler-Setup-<版本>-x64.exe
```

最终使用方只需要双击这个安装包，不需要安装 Node.js、数据库或其他运行环境。

## 6. 发给他人前

1. 确认 `npm test` 全部通过。
2. 在 `release\win-unpacked` 中启动解包应用检查一次。
3. 在一台没有 Node.js 的 Windows 10/11 x64 电脑上安装测试。
4. 检查桌面快捷方式、离线启动、新增数据、重启保留、备份恢复和卸载保留数据。
5. 将安装包和本操作指南一起交付。
